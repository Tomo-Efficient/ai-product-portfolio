上个月各渠道的保费收入环比

全渠道保费收入 3.12 亿元，环比 +5.8%。互联网渠道增速最快（+21.6%），银保渠道小幅下滑（-2.1%）。

SQL · 已通过 Query Checkingdws_policy_premium_di
WITH cur AS (
  SELECT channel_code, SUM(premium) AS premium
  FROM dws_policy_premium_di
  WHERE stat_date >= DATE_TRUNC('month', CURRENT_DATE - INTERVAL '1 month')
    AND policy_status = '有效'
  GROUP BY channel_code
)
SELECT c.channel_name, ROUND(cur.premium/10000,1) AS premium_wan
FROM cur JOIN dim_channel c USING (channel_code)
ORDER BY premium_wan DESC LIMIT 100;
