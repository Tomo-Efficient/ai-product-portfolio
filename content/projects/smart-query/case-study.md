## 01 / 场景

在招商金科，业务人员想看一眼数据，通常要走「提需求 → 排期 → 数据开发写 SQL → 导表 → 解读」的链路，单次分析平均要 **6 小时**。问题不是没有数据，而是**近千个字段、分散的口径、复杂的表关系**，把数据锁在了少数人手里。

智能问数 Agent 的目标很具体：业务人员用自然语言提问，系统生成 SQL、执行并返回文字、数据与图表，把单次分析压缩到 **30 秒**。

## 02 / 为什么通用 NL2SQL 不够

直接让大模型“看着 Schema 写 SQL”，在真实数仓里会碰到四个硬问题：

| 问题 | 典型表现 | 后果 |
| --- | --- | --- |
| 字段语义不清 | `amt` 是保费、保额还是手续费？ | 选错字段，答案看起来对但口径错 |
| 表关系复杂 | 一张宽表背后有 6 个关联表、3 套编码 | JOIN 错、重复计数 |
| 业务口径分散 | “月均保费”在不同报表里有三种算法 | 同一问题不同答案 |
| 安全边界 | 模型可能生成 DELETE / 无 LIMIT 查询 | 数据风险与性能风险 |

所以产品重点不是“接一个模型”，而是**把 Schema、口径、安全边界和评测做成系统**。

## 03 / 方案

### 四层数据准备

1. **元数据层**：表、字段、类型、注释、字段语义澄清、脏数据说明。
2. **关系层**：表关系、主外键、编码对齐映射（如渠道编码在两张表里不一致）。
3. **业务层**：业务数据解释、同义词词典（“保费收入”=“已赚保费”=“premium_income”）。
4. **指标层**：指标平台、公式化知识库，把“月均保费”这类口径固化成可检索的知识。

这四层不是文档工程，而是**检索与 Prompt 的输入**。没有它们，模型只能猜。

### 复杂度路由

不是所有问题都值得跑一个 Agent：

- **简单查询**：单表、明确时间与维度 → few-shot 改写，直接生成 SQL。
- **中等查询**：多表 JOIN、聚合、口径需要澄清 → Decomposition + CoT，把问题拆成子问题。
- **复杂查询**：多轮追问、需要探索数据、跨主题 → ReAct Agent Loop（任务拆解 → 工具调用 → 自我反思 → 结果输出）。

路由让成本和延迟可控，也让简单问题不会被复杂流程拖慢。

### 混合检索 + evidence

向量召回负责“语义相近”，倒排索引兜住表名、字段名、编码等精确术语；两路结果合并去重后，作为 evidence 拼进 Prompt。检索不到时明确降级为“请补充口径”，而不是硬编一个表名。

### Query Checking 与安全护栏

生成 SQL 之后不是直接执行，而是先过一轮检查：

- 语法与方言检查；
- 表 / 字段是否存在、是否在授权范围；
- 是否缺少时间过滤、是否可能全表扫描；
- AST 解析拒绝 `DROP` / `DELETE` / `UPDATE`；
- 自动追加 `LIMIT`；
- 敏感字段脱敏；
- 失败时带错误信息回给模型做一次修复。

## 04 / 评测

评测不只看“SQL 能不能跑”，而是按四段归因：

| 环节 | 看什么 | 典型 badcase |
| --- | --- | --- |
| 选表 | 是否选对主表与关联表 | 用宽表代替明细表，口径被预聚合 |
| 条件 | 时间、渠道、状态过滤是否正确 | 漏掉退保状态 |
| 聚合 | 去重、口径、粒度是否正确 | JOIN 后重复计数 |
| 口径 | 指标定义是否与业务一致 | “月均”按自然月还是滚动 30 天 |

组织数据开发接入 10+ 个真实 ETL 脚本、近千个字段做灰度测试；每次失败都回填到评测集，形成“问题 → 归因 → 修 Prompt / 修知识 → 回归”的闭环。

## 05 / 结果

- SQL 运行答案正确率稳定在 **85% 以上**。
- 单次业务分析周期从 **6 小时缩短到 30 秒**。
- 单次分析耗时平均减少 **90%**。
- 建立了只读账号、AST 拦截、自动 LIMIT、敏感字段脱敏四道安全边界。

## 07 / 取舍与下一步

**取舍**：没有一上来做“全自动 BI”。先把高频、可归因的问数场景做准，再扩展图表和多轮探索；没有用端到端模型直接替代数仓，而是让 Agent 在既有权限与口径体系内工作。

**下一步**：

- 把“追问澄清”做成结构化槽位（时间、口径、维度），减少无效多轮；
- 对高频问题做物化视图与缓存，进一步压低 P95；
- 把评测集扩到跨主题问题，观察正确率随 Schema 规模增长的衰减；
- 用人工抽检校准 LLM-as-judge，避免自动评测自嗨。
